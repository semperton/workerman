# Security

## Supported versions

| Version | Supported |
|---|---|
| 1.x | yes |

## Reporting a vulnerability

Please don't open a public issue. Report it privately with a
[security advisory](https://github.com/semperton/workerman/security/advisories/new),
including the request that triggers it if possible.

Fixed versions are released before the advisory is published.

Vulnerabilities in Workerman itself are fixed upstream, [walkor/workerman](https://github.com/walkor/workerman);
report them there, and here if this package can protect against them in the meantime.
